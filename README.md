# English Teacher Toolkit PRO

A comprehensive Excel-based toolkit for English language teachers.

## Features

- CEFR Curriculum (A1–C2)
- Grammar Bank
- Vocabulary Bank
- Lesson Plans
- Movie Library
- Song Library
- Student Management
- Teaching Resources
- Dashboard
